# KKMongin
Prototype mobile-first inventory outlet.

Fokus: Daily SO raw material di bar, IN warehouse/vendor ke backroom, OUT backroom ke bar, FEFO raw material, Kitchen Supplier terpakai, Merchandise terjual, Stock Awal, Estimasi Order, Penjualan 30 hari + buffer, dan PWA.

Data demo memakai localStorage. Login ini DEVELOPMENT ONLY, bukan authentication production.

Demo: admin/admin, manager/manager, staff/staff, viewer/viewer.
